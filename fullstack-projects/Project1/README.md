# MERN Task Manager App

Full stack MERN application with authentication, role-based access, notes, tasks, image upload and CRUD operations.

## Features
- User Authentication (JWT + Cookies)
- Role Based Access (Admin/User)
- Notes CRUD
- Tasks CRUD with Status (Todo/Doing/Done)
- Profile Image Upload
- Protected Routes
- Search & Pagination

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Cloudinary
- JWT

## Run Locally

Backend:
```sh
npm install  
npm run dev  
```
Frontend:
```sh
npm install  
npm run dev  
```
